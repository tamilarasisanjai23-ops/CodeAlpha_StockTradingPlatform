# Advanced Stock Trading Platform

## Project Overview
The Advanced Stock Trading Platform is a Java-based console application that simulates basic stock trading operations. Users can view stocks, buy and sell shares, track their portfolio, view transaction history, and simulate stock price updates.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList and Collections
- File Handling
- Exception Handling

## Features
- View available stocks and prices
- Buy stocks with balance validation
- Sell owned stocks with quantity validation
- View portfolio and account value
- Calculate simulated profit and loss
- View transaction history
- Update stock prices using simulation
- Save and load data using file handling
- Validate user inputs

## Stocks Available
- TCS
- INFOSYS
- WIPRO

## How to Run

1. Install the Java Development Kit (JDK).
2. Open the project folder in the terminal.
3. Compile the Java files:

   `javac Main.java Stock.java Portfolio.java Transaction.java DataManager.java`

4. Run the application:

   `java Main`

## Project Files
- `Main.java` — Main menu and application logic
- `Stock.java` — Stock details and prices
- `Portfolio.java` — Balance and stock holdings
- `Transaction.java` — Transaction details
- `DataManager.java` — Saves application data

## Disclaimer
This project is an educational simulation. It does not use live stock market data or execute real trades.</
